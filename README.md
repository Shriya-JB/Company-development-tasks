# Company Development Tasks

All development and tasks performed at SpanIdea.

## Overview

This repository contains development tasks, patches, and deployments for SpanIdea projects. It serves as a learning resource and tracking system for development work performed across various running projects.

## Key Learning Outcomes

Through this repository, I have gained experience with:

- **Version Control & Patches**: Creating and deploying patches to running projects
- **Source Code Management**: Downloading and organizing source code from various repositories
- **Code Navigation**: Locating and identifying code sections for editing
- **Markup & Documentation**: Working with markup files and documentation
- **Real-world Development Workflow**: Understanding how actual developers manage code, patches, and deployments

## Getting Started

To work with this repository:

1. Clone the repository to your local machine
2. Explore the project structure to understand the codebase
3. Locate the specific code sections you need to edit
4. Create patches for your changes
5. Test patches before deploying to running projects

## Repository Structure

- Documentation of development tasks
- Patch files for project deployments
- Source code references and examples
- Learning resources and notes

## Development Workflow

This repository follows a standard development workflow:
1. Download source code
2. Make necessary changes
3. Create patches
4. Test in development environment
5. Deploy to running projects
